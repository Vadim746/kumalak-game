# Кумалак (Тогыз кумалак)

**Кумалак** (каз. *тоғызқұмалақ*, тат./баш. *тугыз кудалак*) — тюркская народная
настольная игра семейства **манкала**. Распространена у **казахов, татар, башкир
и киргизов**; в Российской Федерации особенно известна в **Татарстане
и Башкортостане**. Название переводится как «девять кумалаков»: *кумалак* — и камешек,
и сама игра.

Это десктопное приложение: игра против компьютера с подсчётом очков в «казанах»,
меню с экраном правил, ввод имени, три уровня сложности и таблица рекордов
с фильтром. Оформление выдержано в казахо-татарском стиле: тёмно-зелёное сукно,
золото, деревянная доска с орнаментом, шрифты Marck Script и PT Sans.

> Реализован вариант **«Тогыз кумалак» (9×9 отау, 162 кумалака)** по описанию
> этнографа **Н. Н. Пантусова (1906)** — первого наиболее полного описания игры.
> Расхождения между источниками и принятые решения явно перечислены в разделе
> [«Варианты правил и принятые решения»](#варианты-правил-и-принятые-решения).

## Возможности

- **Меню**: «Играть», «Правила», «Таблица рекордов», «Выход»; внизу — лучший результат.
- **Экран правил** с прокруткой: история, народность, схема доски, термины, ссылки.
- **Ввод имени** перед партией с проверкой ошибок (пустое имя / короче 2 символов).
- **Три уровня сложности** бота: «Лёгкий», «Средний», «Сложный».
- **Форматы матча**: одна партия либо до 100 / 150 / 200 кумалаков в казане.
- **Партия**: доска 2×9, казаны, анимация посева и захвата, подсказка, журнал ходов
  с нотацией, диалог подтверждения туздыка, кнопки «Сдаться» и «В меню».
- **Экран итогов**: счёт, победитель, число ходов и автоматическое сохранение рекорда.
- **Таблица рекордов**: фильтр по имени (подстрока, без регистра), сортировка
  по очкам/дате, очистка с подтверждением, пустые состояния.
- Звуки синтезируются программно (`wave` + `array`), внешних аудиофайлов нет.

## Установка и запуск

Нужен **Python 3.14** (проверено на 3.14.10) и графическая библиотека
**`pygame-ce>=2.5.0`**. Системный `pygame 2.6.1` на этой машине сломан
(в колесе отсутствует скомпилированный модуль `pygame.font`), поэтому
используется виртуальное окружение проекта. **numpy не нужен и не используется**.

Скопируйте и выполните целиком:

```bash
cd ~/Projects/kumalak-game
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

Эквивалентно ручной установке: `.venv/bin/pip install "pygame-ce>=2.5.0"`.
Все команды ниже выполняются из корня проекта через `.venv/bin/python`.

> `pygame-ce` — свободная сборка pygame с тем же API (`import pygame`).
> На дисплее `DISPLAY=:1` приложение можно открыть вручную для визуальной проверки.

## Управление и экраны

| Экран | Что делает |
| --- | --- |
| **Меню** | Кнопки «Играть», «Правила», «Таблица рекордов», «Выход»; показ лучшего результата. |
| **Правила** | Прокручиваемый текст: история, народность, схема доски, п. 3.1–3.5 ТЗ, термины, источники. Кнопка «Назад». |
| **Ввод имени** | Поле имени (кириллица), выбор сложности и формата матча, «Начать игру». Пустое имя → сообщение об ошибке. |
| **Партия** | Счёт «Вы: X — Y: Бот», номер хода, индикатор хода, доска, журнал, подсказка, confirmation туздыка, «Сдаться», «В меню». |
| **Итог матча** | Счёт, победитель, число ходов, уведомление «Рекорд сохранён»; «Играть снова», «Таблица рекордов», «В меню». |
| **Таблица рекордов** | Фильтр по имени, сортировка, список записей, «Очистить всё» с подтверждением. |

**Управление:** мышь — клики по кнопкам и лункам; клавиатура — ввод имени,
`Esc` — назад/в меню. От меню до партии — не более двух кликов («Играть» → «Начать игру»).

## Как играть

1. В меню нажмите **«Играть»**.
2. Введите имя (оно попадёт в таблицу рекордов), выберите сложность и формат матча,
   нажмите **«Начать игру»**. Пустое имя или имя короче 2 символов не принимается.
3. Кликайте по **своим** непустым отау, чтобы сделать ход; кумалаки раскладываются
   автоматически, захват и атсырау считаются сами. Клик по лунке соперника — подсказка,
   что ходить туда нельзя.
4. Если ход даёт право поставить туздык — подтвердите «Да» или откажитесь «Нет».
   Кнопка **«Подсказка»** подсвечивает доступные ходы и показывает номер лунки,
   куда упадёт последний кумалак.
5. После окончания матча результат автоматически сохраняется в таблицу рекордов.

## Правила игры

Полный текст доступен на экране **«Правила»** в приложении. Ниже — краткая справка.

### Доска и фигуры

- Доска состоит из **двух рядов по 9 лунок-отау** (18 всего) и двух больших чаш-**казанов**
  по краям; свой казан стоит на стороне соперника.
- Всего **162 кумалака**: в начале в каждой из 18 лунок лежит по 9, казаны пусты.
- Нумерация лунок — **от 1 до 9 со своей стороны**: белые считают слева направо,
  чёрные — справа налево (со своей точки зрения).

### Посев

- Ход делается из любой своей непустой лунки. Кумалаки раскладываются **по одному
  против часовой стрелки**: сначала по своим лункам слева направо, затем по лункам
  соперника справа налево, и так по кругу.
- Если в лунке было **больше одного** кумалака, **первый остаётся** на месте,
  остальные идут дальше; если был ровно **один** — он перекладывается в следующую лунку.
- **Казаны не входят в круг посева.**

### Захват (чётность)

Если последний разложенный кумалак попал в **лунку соперника** и сделал там
**чётное число** (2, 4, 6, …), игрок забирает **все** кумалаки из этой лунки
в свой казан. Захват происходит автоматически; чётное число в своей лунке или
в лунке соперника, в которую последний камень не попал, захвата не даёт.

### Туздык — «священное место в степи»

- Если последний кумалак попал в лунку соперника и сделал там **ровно 3**,
  игрок **может** установить там туздык (лунка становится «десятой» его лункой).
  В интерфейсе это явный выбор «Да/Нет», у бота — решение по оценке позиции.
- **Из туздыка нельзя ходить.** Все кумалаки, попадающие в туздык любой стороной,
  забирает **владелец туздыка**.
- Ограничения: можно иметь **только один** туздык; нельзя ставить его в **9-ю лунку**;
  нельзя ставить в лунку с **тем же номером**, где уже стоит туздык соперника.

### Конец партии и счёт

- **Победа сразу:** как только в казане игрока становится **82 или более**
  кумалаков (половина от 162 плюс один), партия заканчивается его победой.
- **Атсырау (атсыз қалу):** если у игрока, чей ход, не осталось ни одного хода,
  соперник забирает в свой казан **все** оставшиеся на доске кумалаки, затем
  сравниваются казаны.
- Больше кумалаков в казане → победа; ровно **81:81 → ничья**.
- Первый ход делает игрок-человек («белые»).

### Нотация и арифметика

Ход записывается как «**откуда куда**», например `76` (из лунки 7 с последним
кумалаком в лунке 6). Установка туздыка помечается `x`: `36x`. Нотация выводится
в журнале ходов.

Для подсказки номер лунки последнего кумалака считается по формуле
«**номер лунки + число кумалаков в ней**» (нумерация от игрока):

| Сумма | Результат |
| --- | --- |
| ≤ 10 | сумма − 1 |
| 11…19 | сумма − 10 |
| 20…28 | сумма − 19 |
| 29…37 | сумма − 28 |

Например, `7 + 9 = 16 → 6`. Значения всегда лежат в диапазоне 1…9; номер больше 9
означает лунку на стороне соперника.

### Термины

| Русский | Кумалачный термин |
| --- | --- |
| камешек, шарик | **кумалак** |
| маленькая лунка (18 шт.) | **отау** |
| большая чаша (2 шт.) | **казан** |
| священная лунка | **туздык** |
| позиция без хода | **атсырау / атсыз қалу** |

## Варианты правил и принятые решения

Источники расходятся в деталях. Ниже зафиксировано, что именно реализовано,
**ничего не изменено молча** (ср. п. 2 и п. 3 ТЗ).

1. **Три камня при установке туздыка уходят в казан владельца.** Когда ход делает
   лунку соперника равной 3 и игрок подтверждает установку туздыка, эти **3 кумалака
   сгребаются в казан** установившего туздык, а сама лунка остаётся пустой и впредь
   только поглощает попадающие в неё камни. В ряде описаний triggering-камни
   остаются «замороженными» в священной лунке; здесь выбран забор в казан — так
   проще вести счёт и сохранять инвариант 162 кумалака.
2. **Ход из туздыка запрещён.** Лунка с туздыком блокируется для игрока, на чьей
   стороне она находится (п. 3.4 ТЗ): он не может ходить из неё, хотя чужие камни
   туда попадают и сразу идут в казан владельца туздыка.
3. **`last_landed_pit()` возвращает номер 1…9, а не индекс 0…17.** Это номер лунки
   в нумерации её владельца, соответствующий таблице арифметики п. 3.6 ТЗ
   (например, `7 + 9 → 6`). Внутри доска хранится плоским списком из 18 индексов:
   `0…8` — отау белых, `9…17` — отау чёрных; перевод в номер и обратно делают
   вспомогательные функции.
4. **`move_number` начинается с 0** и увеличивается на 1 после каждого применённого
   хода. В журнале и в UI для удобства показывается номер с единицы (`move_number + 1`),
   но внутренний счётчик нулевой — это упрощает индексацию и тесты.
5. **Реализованы оба варианта конца партии.** «Вариант A» (победа сразу при 82+) —
   основной; «Вариант B» (атсырау с забором остатков соперником) — дополнительный.
   Ничья фиксируется только при ровном счёте 81:81 (или при равных казанах после атсырау).
6. **Лёгкий уровень ИИ не ставит туздык** — намеренное упрощение для новичка по п. 5.2 ТЗ;
   средний и сложный уровни оценивают выгоду туздыка и ставят его при возможности.
7. **Первый ход — за человеком («белые»)**, без жеребьёвки и случайного определения
   стороны, которые встречаются в некоторых современных сводках правил.

## Таблица рекордов

- Результат сохраняется **автоматически** после матча в `records.json` рядом
  с программой; если каталог недоступен для записи — в `XDG_DATA_HOME/kumalak-game`.
- Запись содержит: `name`, `score` (казан игрока), `opponent_score`, `result`
  («победа» / «поражение» / «ничья»), `difficulty`, `date`, `rounds`, `moves`.
- Есть **фильтр по имени** (подстрока, регистронезависимо; пустой запрос показывает все),
  **сортировка** по очкам и по дате и **очистка** с подтверждением.
- Запись атомарна (временный файл + `os.replace`). Повреждённый JSON не роняет игру:
  файл откладывается в `records.json.bak`, таблица открывается пустой и показывается
  предупреждение.

## Структура проекта

```text
kumalak-game/
├── main.py                  # точка входа: окно, стек сцен, главный цикл
├── storage.py               # таблица рекордов (JSON, фильтр, сортировка)
├── requirements.txt         # pygame-ce>=2.5.0
├── .gitignore
├── game/                    # игровая логика (не зависит от pygame)
│   ├── kumalak.py           # правила: посев, захват, туздык, атсырау, счёт
│   └── ai.py                # бот трёх уровней (EASY / MEDIUM / HARD)
├── ui/                      # графический слой
│   ├── theme.py             # палитра, шрифты, фон, орнамент, панели
│   ├── widgets.py           # кнопки, поле ввода, прокрутка, сообщения
│   ├── board_render.py      # доска: 18 отау, 2 казана, кумалаки, туздык
│   ├── scenes.py            # экраны: меню, правила, имя, партия, рекорды, итог
│   └── sounds.py            # звуки (wave + array, без numpy)
├── assets/fonts/            # Marck Script, PT Sans (лицензия OFL)
├── tests/                   # unittest: правила, ИИ, хранилище, матч, smoke
└── tools/shots.py           # headless-скриншоты экранов
```

Игровая логика отделена от графики: правила и бота можно тестировать без окна.

## Тесты и скриншоты

```bash
.venv/bin/python -m unittest discover -s tests -t .
.venv/bin/python -m tools.shots          # PNG-файлы в shots/
```

`tools/shots.py` работает без монитора (`SDL_VIDEODRIVER=dummy`) и без эмулятора:
он отрисует сцены в PNG для визуальной проверки. Минимальный набор — не менее
30 тестов, включая полный матч бот против бота и smoke-отрисовку всех экранов.
